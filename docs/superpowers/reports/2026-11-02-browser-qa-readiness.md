[다운로드 방법과 짧은 확인표](../../qa/search-handoff/README.md), [단일 HTML 데모](../../qa/search-handoff/demo.html), [데모 자동 검증 결과](../../qa/search-handoff/automated-results.json)를 제공한다. HTML은 생성 시점의 고정 스냅샷이며 개발 도구 설치나 로컬 서버 없이 연다. GitHub 소스 미리보기에서 HTML을 실행하는 방식은 아니다.

입력은 기존 검색 평가 corpus에 페이지 이동용 합성 로그 55건과 명시적 HTTPS 링크를 추가한 것이다. 총 로그 61건, 입력 출처 9개이며 실제 프로젝트나 개인 기록은 수집하지 않았다. 인수인계는 필수 섹션 기재 상태가 `complete`이고 기본 5건을 선택하며 56건을 제한으로 생략한다. 이 표시는 실제 검증 성공이나 실행·변경 승인을 부여하지 않는다.

## 남은 사람 확인

Chrome·Edge·Safari에서 실제 파일 열기, 화면 배치·키보드·클립보드 권한·네트워크 관측은 미실시다. Python 3.7과 Windows CLI 실제 실행도 미실시다. 테스트 코드의 DOM 대역은 이를 대신하지 않는다.

처음 보는 사람이 정확한 상태·다음 행동·제약·미검증 사항을 설명하기까지의 60초 재개 평가는 별도로 남아 있다. 이미 검색어와 정답을 읽은 참여자의 기능 QA를 처음 보는 사람의 이해도 평가로 집계하지 않는다. 사람 확인은 다운로드 안내의 양식으로 기록한다.
